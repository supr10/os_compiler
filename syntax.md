# OS-compiler language syntax:

* PRINTCHAR (character) : prints a character on screen
* GETCHAR : waits for a keypress (on keyboard) and stores it
* RESTART : restarts the program (does not reset the screen or the variables)
* displaynum (broken for now) displays the stored number between 0 and 9
* increment/decrement: adds/subs 1 to the variable
* display: displays the currently stored variable (without formating, as an ascii number)
* saveall/loadall: saves all the variables or loads them back
